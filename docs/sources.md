# Sources

| Data | Source / notices |
| --- | --- |
| Pronunciations | CMUdict; `data/upstream/CMUDICT-LICENSE.txt` |
| Letter/sound links | NRC g2p; `data/upstream/NRC-LICENSE.txt` |
| Blending cues | [NIFDI packet](https://www.nifdi.org/videos/video-guides/di-and-science-of-reading-webinar/4134-corrective-reading-decoding-a-b1-b2-and-c-sound-pronunciation-packet/file.html), plus [UFLI’s quick-schwa definition](https://ufli.education.ufl.edu/resources/teaching-resources/glossary/) |
| Spelling patterns | [Hooked on Phonics chart](https://www.hookedonphonics.com/wp-content/uploads/2025/05/44-phonemes-chart-rev2.pdf) |
| Fonts | `public/fonts/sources.json` and adjacent OFL notices |
| Recording previews | `public/audio/manifest.json`, `sources.json` and attribution/license files |
| Frequency test sample | `evaluation/common-words.json` includes wordfreq attribution and CC BY-SA terms |

Source pins and checksums are in `data/sources.lock.json`; explicit teaching rules are in `data/policies/`. Citations do not imply endorsement.

Unresolved or questionable letter links stay unmarked. Pronunciation variants require parent choice. A missing blending cue is separate from a silent letter or an unknown pronunciation.

Recording timings are forced-alignment candidates, not reviewed teaching assets. Browser speech is separate from the selected dictionary pronunciation and has no synchronized timing.
